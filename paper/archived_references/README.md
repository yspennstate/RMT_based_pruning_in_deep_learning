## Berlyand, Bourdais, Owhadi, Shmalo --- "Pruning Deep Neural Networks via a Combination of the Marchenko-Pastur Distribution and Regularization"

ResearchGate: <https://www.researchgate.net/publication/389484743_Pruning_Deep_Neural_Networks_via_a_Combination_of_the_Marchenko-Pastur_Distribution_and_Regularization>

DOI: (publication ID 389484743 on ResearchGate; see record for journal venue)

This is an earlier published version of the same line of work and a key
reference for citation lineage. The current paper inherits its
Marchenko--Pastur regularization / pruning framework and extends it to the
deterministic certificate theory (§5 of current paper) and the structured
CAST/CAST-2E conversion (§3.6). It should be cited when discussing earlier
MP-based pruning + regularization combinations; contemporaneous works cited
there should also be checked for relevance to the current citation list.
