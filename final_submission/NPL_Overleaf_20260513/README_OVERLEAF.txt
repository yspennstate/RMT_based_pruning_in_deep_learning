Neural Processing Letters submission package

Entrypoints:
- main.tex: main manuscript
- ESM_1.tex: Online Resource 1, proofs and mathematical supplement
- ESM_2.tex: Online Resource 2, methodology and numerical supplement

Compile order for fresh builds:
1. main.tex
2. ESM_1.tex
3. ESM_2.tex

The main.aux and ESM_1.aux files are included so Online Resource 1 and Online Resource 2 can resolve cross-resource references in the same Overleaf folder. The compiled PDFs are included for coauthor review.
